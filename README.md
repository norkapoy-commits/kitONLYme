# Personal Toolkit PWA (GitHub Pages ready)

## Deploy
1. Create a GitHub repo (e.g., personal-toolkit).
2. Upload ALL files in this folder to the repo root.
3. Settings -> Pages -> Source: main branch / root.
4. Visit https://<username>.github.io/<repo>/ and use "Install app" / "Add to Home Screen".

Paths are relative so it works at repo root or subpath.
